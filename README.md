# Multimessenger Emission from GOALS Galaxies

This repository models and predicts high-energy neutrino (and secondary gamma-ray) fluxes from galaxies in the **Great Observatories All-Sky LIRG Survey ([GOALS](https://goals.ipac.caltech.edu/))**.

It implements the phenomenological starburst cosmic-ray transport framework of Merckx et al. (2023), which relates a galaxy's infrared luminosity to its expected neutrino output from proton–proton collisions, and applies it across the full GOALS sample as well as to individual sources of interest (NGC 1068, Arp 299).

## Overview

The project compiles multi-wavelength (mainly Herschel far-infrared) electromagnetic data for each source in the GOALS sample, converts it into supernova rates and cosmic-ray injection parameters via IMF-dependent calibrations, and evaluates starburst-driven neutrino (and, in newer additions, gamma-ray) fluxes using an analytic cosmic-ray transport model.

The framework was originally developed to:

- Estimate per-source and diffuse neutrino flux predictions for the GOALS sample and compare them to IceCube's sensitivity and measured diffuse flux.
- Test whether the neutrino emission observed from **NGC 1068** — reported by IceCube as a high-energy neutrino source — can be explained by starburst activity alone, or whether it points to a dominant AGN contribution.
- Extend the same cosmic-ray transport core to secondary **gamma-ray** emission (including internal and extragalactic background light absorption), enabling a joint multiwavelength case study of **Arp 299** against Fermi/gamma-ray data, CTAO North sensitivity, and IceCube point-source sensitivity.

## Scientific Framework

The core physics lives in `helper_functions/cr_transport.py` and is shared between the neutrino and gamma-ray pipelines:

- **Cosmic-ray injection & transport** — supernova-driven proton injection `Q(p)`, the steady-state proton momentum distribution `f(p)`, and the relevant timescales (wind advection, hadronic losses, diffusive escape), following Peretti, Blasi, Aharonian & Morlino (2019) and its follow-up Peretti, Blasi, Aharonian, Morlino & Cristofari (2020).
- **Neutrino production** (`analytic_neutrino_flux.py`) — pion-decay neutrino spectra from proton–proton collisions (Kelner, Aharonian & Bugayov 2006), integrated over the source's proton distribution to give the observed neutrino flux `Flux(E_nu, ...)`, including the 1/3 factor for oscillation into three flavors.
- **Gamma-ray production** (`gamma_flux.py`) — the corresponding pion-decay photon spectrum, plus:
  - internal absorption on the source's own dense far-IR/optical photon field, and
  - EBL absorption over the cosmological path to the observer (via the optional `gammapy` dependency).
- **IMF calibrations** (`imf_calibrations.py`) — converts infrared luminosity into a core-collapse supernova rate using one of several IMF-dependent calibrations (`"Murphy"`, `"Yarno NK"`, `"Yarno TH"`), which in turn sets the cosmic-ray injection rate.

## Installation

The repository has no `requirements.txt`/`environment.yml` at present. Based on the notebook and module imports, you'll need:

```bash
pip install numpy scipy pandas matplotlib astropy jupyter
```

Optional (only required for EBL gamma-ray absorption in `gamma_flux.py`, used by `ARP299_casestudy.ipynb`):

```bash
pip install gammapy
```

`gamma_flux.py` degrades gracefully if `gammapy` isn't installed — `Flux_gamma` still works as long as you don't pass a redshift `z` for EBL absorption.

**Setup:**

```bash
git clone https://github.com/YarnoMerckx/neutrino-flux-GOALS-galaxies.git
cd neutrino-flux-GOALS-galaxies
jupyter notebook
```

> **Note:** `notebooks/repo_root.py` locates the repository root by walking up from the current working directory until it finds a `.git` folder, then adds it to `sys.path` so the notebooks can `import helper_functions...`. This means the notebooks must be run from within a git clone of the repository (not, e.g., a bare extracted ZIP with no `.git` folder).

## Notebook Workflow

Run in order:

1. **[`Generate_dataframe.ipynb`](notebooks/Generate_dataframe.ipynb)**
   Builds the master dataframe: reads Herschel IR luminosities and AGN fractions for the GOALS sample from `data/split-lir/`, computes supernova rates via `imf_calibrations.SNr_IMF`, and calculates starburst-driven neutrino (and gamma-ray) flux predictions using `helper_functions.analytic_neutrino_flux` / `gamma_flux`. Writes the compiled table to `data/tables/dataframe`.

2. **[`GOALS_per_source_predictions.ipynb`](notebooks/GOALS_per_source_predictions.ipynb)**
   Loads the compiled dataframe and generates per-source neutrino flux predictions across the sample, with sanity checks against comparable results in the literature (e.g. Arp 220, NGC 2146).

3. **[`GOALS_diffuse_predictions.ipynb`](notebooks/GOALS_diffuse_predictions.ipynb)**
   Computes the total diffuse neutrino flux from the GOALS population and compares it to IceCube's measured diffuse flux (`data/icecube-diffuse/`) using `helper_functions.diffuse_IceCube_plot`.

4. **[`NGC1068_flux_evidence.ipynb`](notebooks/NGC1068_flux_evidence.ipynb)**
   Compares the model's starburst-driven flux prediction for NGC 1068 against IceCube's evidence-level point-source detection (`data/ngc1068/ngc1068_evidence_flux.txt`). The model's starburst-only prediction falls well below the observed flux, supporting an AGN-dominated origin for the NGC 1068 signal.

5. **[`ARP299_casestudy.ipynb`](notebooks/ARP299_casestudy.ipynb)**
   A multiwavelength (neutrino + gamma-ray) case study of Arp 299: compares the model's predicted SED to its observed gamma-ray SED (Ajello et al. 2020), CTAO North 50h sensitivity, and IceCube 10-year point-source sensitivity.

## Data

| Directory | Contents |
|---|---|
| `data/split-lir/` | Herschel-derived IR luminosities (`lir_split.txt`), AGN bolometric fractions (`agn_split.txt`), source identifiers (`ids.txt`), and the GOALS Herschel sample list with coordinates/redshifts (`goals_herschel_sample_list.txt`) |
| `data/tables/` | `dataframe` — the compiled per-source table (name, coordinates, redshift, luminosity distance, log(L_IR), AGN fraction, SFR, supernova rate, predicted TeV flux) produced by `Generate_dataframe.ipynb` |
| `data/icecube-diffuse/` | IceCube diffuse astrophysical neutrino flux measurements (7.5-year HESE differential flux; 9.5-year νμ upper/lower bands) |
| `data/icecube-sensitivity/` | IceCube 10-year point-source sensitivity vs. declination |
| `data/ngc1068/` | IceCube's evidence-level flux for NGC 1068 |
| `data/ctao-sensitivity/` | CTAO North 50-hour differential sensitivity curve |
| `data/ARP299/` | Multiwavelength SED data points and error boxes for the Arp 299 case study |

## Helper Modules

| Module | Purpose |
|---|---|
| `cr_transport.py` | Shared cosmic-ray injection/transport core (p-p cross section, injection rate, steady-state distribution `f(p)`, timescales) |
| `analytic_neutrino_flux.py` | Pion-decay neutrino spectra and the observed neutrino flux function `Flux()` |
| `gamma_flux.py` | Secondary gamma-ray spectrum, internal absorption, and EBL absorption (optional `gammapy` dependency) |
| `imf_calibrations.py` | IMF-dependent supernova-rate ↔ infrared-luminosity calibrations (`Murphy`, `Yarno NK`, `Yarno TH`) |
| `diffuse_IceCube_plot.py` | Utilities for reading and plotting IceCube diffuse-flux data |
